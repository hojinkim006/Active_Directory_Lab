# Setting up the host

- Set up a mini PC as a dedicated lab server
- Installed extra RAM (24GB total) so several VMs can run at once
- Installed Proxmox VE, the virtual machine monitor that runs every VM in the lab
- Installed Tailscale for secure remote access to the Proxmox web interface without opening ports
